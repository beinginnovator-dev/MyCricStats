# MyCricStats

MyCricStats is migrating to Flutter on the isolated `testing/google-mix-ui` branch.

- Flutter project: `lib/main.dart`, `pubspec.yaml`, `web/`
- Flutter branch setup and scope: [README-FLUTTER.md](README-FLUTTER.md)
- Production app on `main` remains on the existing Cloudflare Pages setup.
- Dedicated Flutter test project: https://mycricstats-flutter-test.pages.dev

The initial Flutter milestone includes Match, Toss, Squads and Stats UI. Live Sportmonks, scoring, commentary, chat, history, ads and tournament features are not yet fully migrated.
